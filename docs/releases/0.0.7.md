# Release 0.0.7 image promotion

The [reviewed plan](./0.0.7-images.json) selects the exact application images
published by the successful [qualified main build](https://github.com/ude-soco/openlap-official/actions/runs/43036330881)
at source revision `1bc7a3ee0d66b4b2750222702b4a098f141b2265`.

This release separates reversible plugin removal and recovery from permanent
artifact deletion. After verifying every backend replica uses this release and
the existing reference guards, configure `PLUGIN_REMOVAL_ENABLED=true` while
keeping `PLUGIN_DELETION_ENABLED=false`. Restored entries start disabled and
stored JARs remain retained. The admin recovery dialog reports these capabilities
separately. See [plugin administration](../plugin-administration.md).

Run **Promote reviewed release images** on **main** with `confirmation_version`
set to `0.0.7`. The workflow loads only the committed release plan for that exact
stable version, checks both immutable sources and both destinations, and copies
the reviewed manifests without rebuilding. It refuses conflicting existing tags
and verifies the complete published pair. Existing matching tags are idempotent.
Release `0.0.6` remains available through its original reviewed plan.

Do not push Git tag `v0.0.7`: existing tag-triggered CI would rebuild and republish
the stable tags. Reserve this image version for the promotion workflow. Registry
writes across two images are not atomic; verify both actual running digests after
deployment. Promotion evidence does not replace backup, restore, application
workflow or deployment acceptance checks.
